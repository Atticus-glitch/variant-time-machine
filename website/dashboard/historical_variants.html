What The Dates Mean

Snapshot date is when the archived ClinVar file was released. Last evaluated is ClinVar’s field describing when the underlying classification was last evaluated; it is not the file download date.

This spreadsheet has two time points, January 2022 and January 2024. It does not reconstruct every update between them. For exact available VCV versions, use Version History.
