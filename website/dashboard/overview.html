Recommended workflow

What To Do

Follow these steps in order for each candidate.

  1. Browse or search the filtered spreadsheet.It opens with only exact older VUS records whose 2024 classification text differs.
  2. Open the row’s timeline.Compare classification, LastEvaluated, review status, gene, conditions, identifiers, submitters, and coordinates at both snapshots.
  3. Check identity and scope.Confirm the Variation ID and Allele ID refer to the same biological variant and inspect condition or aggregation differences. Different text alone is not enough.
  4. Open the official ClinVar page.Use the link in the timeline to check the current record, replacements, conflicts, and record context.
  5. Inspect exact VCV versions when needed.The two release files show two time points, not every intermediate update. Use Version History Explorer for available version-by-version records.
  6. Record a manual decision.Mark the case verified, ambiguous, or excluded in the pilot tools. Do not use unreviewed automatic differences as scientific conclusions.

Important limits

What This Does Not Prove

  • A changed aggregate classification is not automatically a confirmed medical reclassification.
  • `LastEvaluated` is a ClinVar source field; it is not the release date or download date.
  • The broad spreadsheet contains two snapshots only. Intermediate changes require exact VCV history review.
  • Condition scope, merged records, complex alleles, and conflicting submissions can make an apparent change ambiguous.
  • This research site is not a medical device and must not be used for clinical decisions.
