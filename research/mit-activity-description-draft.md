# MIT Activity Description Draft

## Activity Name

Variant Time Machine: independent computational genetics research

## Role

Independent student researcher and software developer

## Concise Description

Built a reproducible pipeline and dashboard using official historical ClinVar snapshots to test whether older information predicts the later benign/pathogenic direction of VUS aggregate classifications. Designed matching and leakage controls, frozen model versions, group-disjoint tests, baselines, error review, and honest limitations. V8 recorded 87.12% balanced accuracy on a sealed 1,000-record retrospective test; a paired interval did not establish improvement over V7.

## If a Shorter Field Is Required

Built a historical ClinVar ML study and dashboard with frozen versions and leakage controls; reported V8's 87.12% balanced accuracy and inconclusive V7 comparison.

## Accuracy Boundary

I built the project independently, but it is not independently or clinically validated. It predicts direction only within a cohort selected for clear later outcomes, not whether a VUS will resolve, and it provides no diagnosis or medical advice. Do not claim publication, deployment, mentorship, public impact, clinical utility, or V8 superiority unless separately verified.
